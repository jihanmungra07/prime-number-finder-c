# prime-number-finder-c
An implementation of the Sieve of Eratosthenes algorithm to find prime numbers efficiently using the C programming language.
# Use
The algorithm can generate all the prime numbers less than or equal to n, where n is an integer entered by the user and is greater than 2.
# Example
Input: 10  
Output: 2, 3, 5, 7
# Compilation
gcc sieve.c -o sieve
# Running
./sieve
